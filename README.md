# Daily Sanctuary

A quiet, local daily place for reflection, small habits, and continuing.

## Features

- Daily quote (original + real human quotes)
- Meditation timer
- **Habit stack** — fully editable
- Private daily reflection + **Look back**
- Color scheme picker + Dim toggle
- Ask an AI menu

No images / scenes — kept deliberately simple and calm.

## Privacy

- Everything personal stays on your device
- No account, no analytics
- AI links leave the local space by design
